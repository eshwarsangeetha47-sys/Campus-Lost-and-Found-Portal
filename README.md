# Campus Lost and Found Portal

## Project Description
The Campus Lost and Found Portal is a web-based application developed for Sai University. It helps students report lost and found items, search for belongings, and submit claims online.

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- JSON Web Token (JWT)
- Render

## Features
- Student registration and login
- Secure authentication
- Report lost and found items
- Browse and search items
- Filter by category and location
- Sort items by date
- Submit claims for found items
- Student dashboard
- Admin dashboard
- Approve or reject claims
- Logout and protected routes

## Installation and Setup

1. Clone the repository.
2. Open the project folder in VS Code.
3. Install dependencies:

   `npm install`

4. Create a `.env` file in the root folder.
5. Add your MongoDB connection string and JWT secret privately:

   `MONGO_URI=your_mongodb_connection_string`

   `JWT_SECRET=your_secret_key`

6. Start the server:

   `npm start`

7. Open http://localhost:3000 in your browser.

## Deployment
The application is deployed using Render, with MongoDB Atlas as the database.
